# Apify actors

Small, polite data tools published on the [Apify Store](https://apify.com/store). Each folder is a standalone actor with its own README, input/dataset schemas, tests and a sample of real output.

| Actor | What it returns |
|---|---|
| [lever-job-metadata](actors/lever-job-metadata/) | Current job postings from the public Lever boards you choose: title, team, location, workplace type, published salary ranges, source links. |
| [uk-food-hygiene-ratings](actors/uk-food-hygiene-ratings/) | Official UK Food Standards Agency hygiene ratings: business, address, rating, inspection date, scores, coordinates, source links. |

Both use only public, documented endpoints, check robots.txt at runtime, pace their requests, and never log in or collect personal contact data.
